Design Principles

Operator's Console

  • Anchor + Panel: 核心指标做锚点，其余信息内联。一眼判断，按需钻取。
  • Data-Is-Mono: 所有数值使用 font-mono (JetBrains Mono)。标签使用 body font。
  • Single Accent: Circuit Teal 是唯一主色。状态色只用于语义（success/warning/danger/info）。
  • Flat-By-Default: 无阴影卡片、无装饰边框、无渐变。信息本身提供视觉层次。
  • Select over Buttons: 筛选器用下拉框，不用按钮组。防止 20+ 选项溢出。
  • Dense Tables: 紧凑行高 36px，表头 muted 色。数据密度优先于留白。
  • Action Links: 操作用文字链接式按钮，不用 icon-only。明确语义，降低认知成本。
