## 功能性 Bug

### BUG-1: hasActiveFilters 始终为 true（UX 缺陷，非数据 bug）

**位置**: `Logs.vue` L284-286

```typescript
const hasActiveFilters = computed(() => {
  const params = buildFilterParams();
  return Object.keys(params).length > 0;
});
```

**原因**: `buildFilterParams()` 在默认状态下（period="5h", 无自定义日期, 所有 select="all"）仍返回 `{ start_time: "..." }`，导致 `hasActiveFilters` 始终为 `true`。

**影响**:
- 当日志列表为空时，始终显示 "No logs match the current filters" + "Clear all filters" 按钮
- 点击 "Clear all filters" 后 `hasActiveFilters` 仍然为 true，UI 无变化
- 不影响数据正确性，仅影响空状态下的用户体验

**修复方案**: 区分"默认过滤参数"和"用户主动设置的过滤参数"。可以检查是否有超出默认 period 的过滤条件：

```typescript
const hasActiveFilters = computed(() => {
  return (
    providerFilter.value !== "all" ||
    modelFilter.value !== "all" ||
    keyFilter.value !== "all" ||
    statusFilter.value !== "all" ||
    !!dateRange.value.start ||
    !!dateRange.value.end
  );
});
```
